\bigskip
{\bfseries Masks for top2018.}
The lab did not supply mask files; it supplied the pruned chain files.
\fn{build_ersatz_pdbs.py} derives our \fn{.mask} file for each chain from the residues
present in the lab's pruned file. The filter (\fn{filter_pruned_residues.py}) reads the file's
\texttt{USER INC} records as the fragment boundaries. So for top2018 the lab's filter is already applied; we do not apply
filter rules ourselves. The rules (Williams et al.\ 2022, and the database's per-residue
filter flags) serve only to check the result.
